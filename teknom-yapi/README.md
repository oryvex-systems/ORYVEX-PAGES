# TEKNOM YAPI WEB — ORYVEX Managed

Responsive TEKNOM YAPI kurumsal web uygulaması.

## Ekranlar
- Ana Sayfa
- Kurumsal
- Faaliyetlerimiz
- Projeler
- Proje Detay
- Teknolojimiz
- Katalog
- İletişim

## Deploy
Cloudflare Pages proje kökü: `teknom-yapi/`
Build command: yok
Output directory: `.`
Canonical domain: `https://www.teknomyapi.com.tr`

## ORYVEX
Deploy ve SSL politikaları `oryvex/` klasöründedir. Nameserver değişikliği, DNS kaydı silme, domain transferi, ödeme ve credential değişikliği manuel onay gerektirir.

## Tasarım standardı
Kırık beyaz + kömür siyah + klasik altın; serif başlık, sade sans-serif gövde; gerçek TEKNOM proje görselleri; ağırbaşlı, mimari, sanatsal ve teknik kurumsal dil.
